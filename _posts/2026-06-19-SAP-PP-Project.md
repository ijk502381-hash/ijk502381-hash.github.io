## SAP PP Implementation Project
This project was about implementing the PP module for a furniture manufacturing company.
I set up the production process from master data to production order confirmation, integrated with SD, MM, and FI.
I created work centers, BOMs, and routings, then ran MRP and processed production orders.
I also developed custom ABAP programs to support production planning.


## Tech
* PP configuration: CR01, CS01, CA01, CO01, CO11N
* Demand planning and MRP: MD61, MD62, MD04
* ABAP: PIR program using BAPI_REQUIREMENTS_CREATE / BAPI_REQUIREMENTS_CHANGE, custom MRP program, custom tables (SE11)
* Troubleshooting: fixed a production order confirmation error through OPK4 configuration


## Duration
2026/03 ~ 2026/06
